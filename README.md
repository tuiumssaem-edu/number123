# 숫자 놀이 모음

초등학교 1학년 수준의 수학(50까지의 수) 학습 웹앱입니다.

1. 수의 순서 알기: 1 큰 수, 1 작은 수, 이어 세기
2. 10씩 묶어 세기: 10개씩 묶음과 낱개로 수 세기
3. 1~50까지의 수: 수 배열표 빈칸 채우기

`index.html` 파일 하나로 작동합니다. 크롬이나 엣지에서 열어 사용하세요.
선생님 설정은 각 놀이 첫 화면 오른쪽 위 ⚙️ 버튼에 있습니다.

## 파일 구성
- `index.html`: 표지와 세 가지 놀이를 묶은 전체 앱
- `apps/`: 각 놀이를 따로 쓸 수 있는 개별 파일
